# GameEngine



Hey, whoever is reading this thanks for opening the link.



This is repo for the game engine project in development by me, this is not a full scale game engine, just a small showcase of my skills of C++ and rendering.



I have implemented a 3D renderer, using OpenGL.

This includes, importing fbx/glb file and mapping respective textures, I have kept it simple and implemented ping pong lighting which includes, specular lighting, shadow mapping, soft shadows and few post processing effects like bloom, etc. You can check the shaders in assets/. glsl type files.



AS for the game play logic, I am currently writing my own collision detection using grid based collider system. The physics thread runs separately for now from the rendering thread.
